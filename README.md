
# Static Website with GitHub Pages

## DevOps Internship - Task 6

### Objective
Deploy a static website using GitHub Pages.

### Technologies Used
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

### Features
- Responsive personal portfolio
- About Me section
- Technical Skills section
- Featured DevOps project
- Navigation links

### Deployment Steps
1. Created the website using HTML and CSS.
2. Uploaded the source files to GitHub.
3. Enabled GitHub Pages from repository Settings.
4. Selected the main branch and root folder.
5. Verified the published website.

### Outcome
